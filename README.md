# hatuira

Свет, выключатели и шторы Home Assistant в терминале. Лампы сами перекрашиваются в цвет темы Omarchy.

```bash
curl -fsSL https://raw.githubusercontent.com/Baklatech/hatuira/main/install.sh | bash
hatuira          # спросит адрес Home Assistant и токен
hatuira --demo   # выдуманный дом, чтобы просто посмотреть
```

[Подробно](docs/guide.md).
