# hatuira

Свет, выключатели и шторы Home Assistant в терминале. Один список по комнатам,
ничего лишнего: ненужные устройства прячутся одной клавишей, а выбранные лампы
перекрашиваются в цвет темы Omarchy при каждой её смене.

Чистый Python ≥ 3.10, без зависимостей. На Omarchy цвета интерфейса берутся из
текущей темы, на остальных системах используется встроенная палитра.

## Установка

    ./install.sh              # из клона, в ~/.local, без root
    curl -fsSL https://raw.githubusercontent.com/Gnome627/hatuira/main/install.sh | bash
    ./install.sh --uninstall  # удалить; настройки в ~/.config/hatuira остаются

Скрипт работает на Arch и на Debian-подобных (Debian 12+, Ubuntu 22.04+): если нет
`python3`, ставит его через `pacman` или `apt` (только тут и нужен `sudo`), кладёт
программу в `~/.local` и добавляет значок в список приложений. Ключи:
`--prefix=DIR`, `--no-deps`, `--no-menu`, `--no-hook`.

На Omarchy он вдобавок добавляет пункт «Hatuira» в системное меню (блок с метками в
`~/.config/omarchy/extensions/omarchy-menu.jsonc`, перед первой правкой делается
копия файла) и хук `~/.config/omarchy/hooks/theme-set.d/hatuira`, который после
смены темы запускает `hatuira sync`. `--uninstall` убирает всё это.

## Запуск

    hatuira            # первый запуск спросит адрес и токен
    hatuira --demo     # выдуманный дом, без сети и токена
    hatuira setup      # сменить адрес или токен
    ./bin/hatuira      # то же прямо из клона, без установки

Токен — «долгосрочный токен доступа»: Home Assistant → профиль → Безопасность.
Он лежит в `~/.config/hatuira/config.json` (права 0600). Вместо самого токена можно
хранить команду, которая его печатает (`"token_cmd": "pass show home/ha"`) — тогда
токен на диск не попадает. Для самоподписанного сертификата: `"insecure": true`.

В список попадают только сущности `light`, `switch` и `cover`. Комнаты берутся из
Home Assistant; если их там нет, список делится на свет, выключатели и шторы.

Home Assistant не сообщает, чем управляет `switch`, а большинство из них — настройки
роутеров, телефонов и дополнений. Поэтому сами в список попадают только выключатели,
похожие на свет: по имени или id (`свет`, `лампа`, `люстра`, `light`, `lamp`, `led`…)
либо по значку с лампой. Остальные лежат среди спрятанных: `a` показывает их, `x`
возвращает нужный в список насовсем (ключ `shown` в конфиге).

## Клавиши

| Клавиша | Действие |
|---------|----------|
| `↑` `↓` / `j` `k` / колесо | выбрать устройство |
| `space` / `enter` | включить / выключить; штора — открыть / закрыть, в движении — остановить |
| `←` `→` / `h` `l` | яркость или положение шторы, шаг 10 % |
| `c` | палитра: лампа сразу принимает цвет под курсором, `enter` или `esc` — назад к списку |
| `s` | лампа следует цвету темы Omarchy (метка `◈`) |
| `S` | режим темы: один тон на все лампы, основные цвета темы или вся её палитра |
| `r` | дать выбранной лампе другой цвет темы (из тех, что раздаёт текущий режим) |
| `R` | раздать цвета темы заново всем лампам: в миксе и основных цветах перемешивает, в одном тоне возвращает тон |
| `x` | спрятать устройство, `X` — всю комнату |
| `a` | показать спрятанные (метка `×`); там же `x` возвращает их |
| `u` | обновить сейчас и перечитать комнаты |
| `q` | выход |

Мышь: клик по значку слева переключает, клик по шкале ставит уровень, клик по
строке выбирает, клик по цвету в палитре красит выбранную лампу. Буквы работают и
в русской раскладке.

В широком окне (от 84 колонок) палитра всегда видна справа от списка; в узком она
открывается по `c` на месте списка. В ней три части: цвета текущей темы, радуга от
насыщенных тонов к пастельным и белый от тёплого к холодному. Лампам без цвета
доступна только строка белого, остальное приглушено.

Значок лампы горит её настоящим цветом. Состояние опрашивается раз в `interval`
секунд, а сразу после команды — каждую секунду, пока оно устанавливается.

Нажатия не копятся в очередь: команды уходят по одной, и на каждое устройство
отправляется только последнее желание — семь быстрых нажатий дают одну-две команды.
Пока команда в пути, строка показывает то, что вы попросили, и опросы её не
дёргают; настоящее состояние возвращается, когда Home Assistant его подтвердит или
если он за 4 секунды так и не согласится.

## Цвет темы

`s` на цветной лампе добавляет её в список синхронизации. После этого:

- при смене темы Omarchy хук вызывает `hatuira sync`, и все **включённые** лампы из
  списка плавно переходят в цвет темы; яркость не трогается;
- выключенные лампы не трогаются (Home Assistant умеет задать цвет, только включив
  лампу) — они получат цвет темы, когда их включит hatuira;
- лампы без цвета (только яркость или температура) в список не добавляются.

Режимов три, клавиша `S` переключает их по кругу (в шапке `◈`, два-три `◈` или
вся палитра):

- **один тон** — все лампы получают `accent` из `colors.toml` темы;
- **основные цвета** — два-три цвета, на которых держится тема: акцент и те из цветов
  рамки окна, курсора, выделения и текста, что заметно отличаются от него по тону;
  если тема одноцветная, к акценту добавляется самый далёкий от него цвет палитры.
  Цвета раздаются лампам случайно и поровну;
- **микс** — цвета темы (акцент, красный, оранжевый, жёлтый, зелёный, бирюзовый,
  синий, пурпурный) раздаются лампам случайно и без повторов, пока цветов хватает;
  при каждой смене темы раздача новая. В темах, где цвета заданы только как
  `color1`…`color6`, они и берутся.

Клавиша `R` раздаёт цвета заново, не дожидаясь смены темы; раздача всегда отличается
от предыдущей. `hatuira sync` делает то же из командной строки — например, после
включения света обычным выключателем.
Клавиша `r` меняет цвет только выбранной лампы — на другой из тех же цветов; лампа
должна быть включена, следовать за темой ей не обязательно.

## Прочее

    hatuira toggle light.desk    # переключить одно устройство — удобно для хоткея в Hyprland

Ключ `settings` в конфиге: `interval` (5 с), `step` (10 %), `mode` (`single`, `main` или `mix`),
`color` (`accent` — цвет для режима одного тона, любой ключ из `colors.toml`: `blue`,
`orange`, `magenta`…), `transition` (1 с, плавность
перехода цвета; 0 — мгновенно). Списки `hidden` и `sync` там же, их можно править
руками.

    python3 -m unittest discover -s tests
